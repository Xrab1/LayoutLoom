# 页织工坊（LayoutLoom）

页织工坊是一款 Windows 本地文件处理工具，面向 PDF、Office、图片和视频的批量转换与编辑。

> [!IMPORTANT]
> **WPS Office 与 Microsoft Office 均已完成独立识别和定向适配。** 自动模式按 WPS → Microsoft Office → LibreOffice 尝试，也可从主界面锁定单一引擎；显式锁定后失败不会暗中切换。WPS 与 Microsoft Office 会保留各自的原生排版特性，复杂文件可按本机版本和实际结果选择表现更好的引擎。LibreOffice 作为兼容回退，部分复杂版式可能与桌面 Office 存在差异。

页织工坊是自由开源软件，采用 **GNU AGPL v3 或更高版本**发布。用户可以免费使用、学习、修改和再分发；分发修改版或通过网络向用户提供修改版功能时，需要按 AGPL 提供对应源代码并保留版权及许可证说明。完整条款见 `LICENSE`，第三方组件说明见 `THIRD_PARTY_NOTICES.md`。

> 兼容性说明：公开品牌、程序名和发布包均已使用“页织工坊 / LayoutLoom”。内部 Python 包目录暂时保留 `docuforge`，仅用于避免破坏已有导入、旧版固定坐标 Word 标记与升级兼容，不再作为产品名称使用。

当前版本不再追求功能数量，公开目录已从 95 项收敛为 **73 个核心任务**。主界面默认只显示本机能够运行的任务；勾选“显示需要额外安装的核心功能”后，才会看到需要本机 WPS、Microsoft Office、LibreOffice 或其他外部组件的入口。

左侧导航已整合为三个一级目录，并采用固定顺序显示，不再把十多个分类平铺在同一层：

- 文档工具：PDF 转换与生成、PDF 页面整理、PDF 压缩与安全、PDF 水印与页码、Office 格式转换、Word 文档处理、Excel 数据处理、PowerPoint 演示处理。
- 图片工具：格式转换与批量、尺寸裁剪与几何、压缩优化与隐私、编辑增强与合成。
- 视频工具：视频生成、转码压缩与提取。

搜索会同时匹配一级目录、二级分区、原分类、任务名称和说明。

主界面采用宽屏、紧凑、窄屏三档自适应布局，并按 Windows 显示缩放使用逻辑像素判断：宽屏完整展示目录与文件工具栏，紧凑窗口自动合并次要文件操作，窄屏把工具目录收为可展开入口。参数区、文件列表和页面内容均可滚动，小屏与高 DPI 下不会再依赖固定窗口尺寸。取色器和视频 PPT 补修工作台也会随可用空间重新排列预览区与时间轴。

界面采用鼠尾草绿、奶油蓝、奶油黄和低饱和雾霾蓝配色，以真正的圆角软卡片组织目录、文件、设置、预览和底部操作区。主流程按“添加文件 → 选择设置 → 开始处理”展示，Office 引擎、动效和缺失组件入口默认收进“偏好设置”。背景只使用柔和波浪色块，不使用 RGB 灯带；按钮保留短促回弹，进度仍保持单向递增。窗口最小化或文件任务运行时会自动降低非必要动画频率，避免视觉效果占用转换性能。

图片裁切、缩放、旋转、翻转、压缩、亮度/对比度/饱和度、滤镜、水印、边框、马赛克和图片叠加等任务会显示“原图 / 效果预览”。参数输入、下拉选择、复选框或取色变化后会自动防抖刷新，不写入文件、不修改原图；批量输入可用“上一张 / 下一张”切换预览对象。裁切和马赛克可直接在左侧原图拖框，程序会换算为原始像素坐标、回填左/上/右/下参数并立即刷新结果。裁切预览还会自动用第一张图片的真实尺寸初始化右、下边界。

所有复选框统一使用空方框和白色“✓”表示关闭/开启，不再使用容易被误认为删除或错误状态的“×”。

“文件与参数”页支持把大量文件或文件夹直接拖入指定列表区域。多文件路径会一次解析，文件夹在后台递归扫描；程序会按当前任务支持的格式自动过滤，并跳过重复或不存在的路径。拖放只读取源文件，绝不会移动或删除原文件，原有“添加文件”和“添加文件夹”按钮仍可继续使用。

## 本机启动

Windows 10/11，Python 3.10 或更高版本：

1. 双击 `安装页织工坊.bat`。
2. 双击 `启动页织工坊.bat`。

从旧版本升级后也需要重新运行一次安装程序，以补齐高精度 PDF 转 Word 所需的 `pdf2docx` 与 `PyMuPDF`。

如果程序已经打开过，更新代码或引擎后请先关闭旧窗口，再重新双击启动；运行中的窗口不会自动加载新目录和新功能。

也可以在 PowerShell 中运行：

```powershell
.\install.ps1
.\run.ps1
```

默认安装已包含 Windows COM 桥接。Microsoft Office 或 WPS 还必须注册可用的 COM 自动化接口；部分 WPS 版本只安装了桌面程序、没有注册该接口，此时软件会明确提示而不会假装转换成功。自动转换优先级为：

1. WPS Office
2. Microsoft Office
3. LibreOffice

自动模式只在当前文档对应的组件之间按上述顺序尝试，并要求输出文件真实存在且非空。显式选择 WPS、Microsoft Office 或 LibreOffice 时只使用所选引擎，失败不会暗中改用其他程序。Office 格式转换中的 Microsoft COM 会同时核验固定 CLSID、注册服务器、实际启动的组件名称及安装目录中的可执行文件，避免 WPS 兼容 ProgID 被误认成 Word、Excel 或 PowerPoint；该转换在隔离子进程中执行，超时或取消时只清理本任务确认新建的 Office 实例，不会按进程名关闭用户原本打开的 Office 窗口。

源码开发环境和 Windows 便携发布版均不会内置 WPS、Microsoft Office 或 LibreOffice。Office 转换仍会检测用户本机已有的三类程序，并保持 WPS → Microsoft Office → LibreOffice 的原有优先级。便携版只内置可再分发的 Poppler 与 FFmpeg；没有独立显卡时，图像增强自动使用 CPU/OpenCV 兼容路径。

若 WPS、Microsoft Office 与 LibreOffice 均不可用，相关 Office 高保真功能会标记为“需要安装组件”。勾选“显示需要额外安装的核心功能”后仍可进入该功能；点击“开始处理”会弹出明确的缺失引擎窗口，并提示安装桌面版 WPS、Microsoft Office，或自行安装 LibreOffice。其他 PDF、图片和视频功能不受影响。

## 核心能力

### PDF

- PDF 转 Word 提供四种彼此独立的内容模式。默认“版式优先混合”优先保持原排版，复杂论文可采用固定坐标；“全文可编辑重建”完整保留原有内置转换方案，适合具有可靠文字层、结构相对简单的数字 PDF；“Microsoft Word 原生转换”直接调用桌面版 Word 的 PDF Reflow，连续复制和常规编辑体验通常更自然，但复杂论文、双栏、特殊字体和分页结果由 Word 自身决定，未安装 Word 时会明确失败且不会回退到其他模式；“整篇高清原样”视觉最稳定，但页内内容不可单独编辑。界面不再额外提供容易混淆的引擎下拉框。
- “旧版固定坐标 Word 兼容升级”位于“兼容修复 / 高级工具”，用于本软件旧版本生成的逐行固定坐标 Word、首次转换时未能完成 WPS 区域优化的文件，以及其他遗留固定坐标 DOCX。它不修改原 Word，也不采用一页一图或标准流式方案，而是按源坐标将页面重建为少量可编辑文本区域，并通过结构检查与真实渲染二重检查改善手机显示和区域内复制。新版 PDF 转 Word 已自动尝试区域优化，新文件通常无需再执行此工具。
- PDF 转 PPT（视觉原样）、PNG/JPG、TXT。
- PDF 图片提取支持原始资源无重采样、按页面可见位置高清还原、相邻图块智能合并及组合模式；可选择页码、格式、DPI、尺寸过滤、去重、批注和 JSON 提取清单。文字和纯矢量图不是内嵌位图，如需整页画面应使用“PDF 转图片”。
- 多张图片合并为 PDF。
- 合并、拆分、提取、删除、插入、旋转页面。
- 无损结构优化、高清有损压缩、已知密码加解密、文字/图片水印（每页可设 1–100 个并自动网格铺排）、页眉页脚和页码。

PDF 转 Word 会对可编辑正文进行字体名称标准化，清理 PDF 子集字体前缀并统一常见字体别名，降低 Word/WPS 中的字体替换风险；全文可编辑模式还会把运行页脚从正文流中独立锚定，避免密集页面把页脚挤成额外空白页。复杂论文、讲义和设计型页面先生成当前高精度固定坐标基线；当逐行定位节点较多且 WPS 可用时，程序会自动生成区域级候选，把大量 `framePr + fitText` 压缩为少量现代文本区域并裁剪空白背景。候选只有同时通过结构检查、真实 WPS 页数/文字/重叠/版面复检以及节点、图片像素和主体 XML 预算检查才会成为最终结果，否则自动保留原固定坐标基线，因此不会为了打开速度牺牲原有精度。版式优先混合模式会自动识别公式、图表、复杂表格和高密度图形区域，也允许使用 `1,3-5` 这类页码表达式强制指定整页高清保留。全文可编辑和混合模式会在保存前校验可编辑正文的字符覆盖率、英文词召回率和词序。混合模式会优先把不适合流式重建的局部区域高清保留，只有无法可靠分区或正文校验仍未通过时才整页兜底。局部图像区域中的文字、公式和表格单元格不能单独编辑，也不会变成 Word 原生公式或表格。高清保留默认 300 DPI，最高可选 600 DPI；数值越高，输出文件通常越大。

“文件与参数”页面提供明显的纵向滚动轨道，并支持鼠标滚轮和触控板滚动；切换处理任务时会回到参数页顶部，避免下方选项被窗口高度遮挡。

PDF 无损压缩遇到单页解压后内容流超过 pypdf 安全阈值时，会保留该页原始编码并继续优化其余页面，不再让整个任务失败。高精度有损压缩不设置软件层面的输入文件体积上限，采用分批渲染降低临时资源峰值，并提供 DPI、JPEG 质量和彩色/灰度下拉选项。

### Office

- Word、Excel、PPT 转 PDF：自动按 WPS → Microsoft Office → LibreOffice 转换，也可显式锁定单一引擎。
- DOC 转 DOCX、XLS 转 XLSX。
- 兼容修复 / 高级工具中的“旧版固定坐标 Word 兼容升级”：仅面向旧版或未成功区域优化的固定坐标 DOCX，输出更适合桌面端、手机端显示和区域内复制的新 Word，并执行结构与真实渲染二重检查；它不再是 PDF 转 Word 的常规后续步骤。
- PPT 转高清图片序列：自动静态渲染同样优先 WPS；显式选择 Microsoft Office 时使用 PowerPoint 原生图片导出，默认宽度 2560 像素。
- Word 转 TXT。
- Excel 转 CSV、JSON、TXT。

Excel 转 PDF 默认使用智能页面布局：逐工作表比较 A4/A3、纵向/横向和安全页边距，优先保持文字可读并避免把相邻列横向拆页；长表只限制页宽，高度仍会自然分页。界面也可选择完全保留原打印设置、固定一页宽或整表单页。自动引擎先尝试 WPS；WPS 启动或导出失败后尝试对应的 Microsoft Excel，仍失败才回退 LibreOffice，避免残留或兼容注册信息造成默认转换失败。

### Word 批处理

- 批量替换文字、删除空白行、删除图片、删除超链接。
- 统一字体/字号/行距，设置页眉页脚。
- 提取文档中的图片。

### Excel 批处理

- 排序、筛选、删除重复值、批量替换。
- 分列、条件格式、提取图片。

### PowerPoint 批处理

- 批量替换字体、添加水印。
- 提取图片/音视频。
- 压缩演示文稿中的图片；默认质量提高到 88，最长边提高到 2560 像素。

### 图片

- JPG、PNG、WebP、BMP、TIFF 互转，可扁平化读取 PSD。
- 调整尺寸、等比例缩放、裁剪、旋转、翻转。
- 压缩、去除 EXIF、亮度/对比度/饱和度、滤镜。
- 高保真 AI 清晰增强：传统去噪、局部对比度和限幅锐化后，可使用 Real-ESRGAN NCNN Vulkan 做 2/4 倍本地增强；增强结果会执行全局结构与分块二重检测，异常分块自动恢复为真实像素放大结果。提供“自动”“无独显兼容增强”和“GPU AI 高清增强”三个明确选项；没有独立显卡时只使用 CPU/OpenCV，不会阻断任务。
- 文字/图片水印、边框、马赛克、拼接、叠加、批量重命名。

图片压缩默认质量提高到 88，默认不再自动缩小像素；调整尺寸的默认画布改为 1920×1080。

常规批量图片处理会根据 CPU 和任务数量自动使用最多 4 个工作线程，同时保持输入与输出顺序一致。90°/180°/270°旋转采用像素无损路径；等比例尺寸处理允许小图按目标尺寸正确放大；长图拼接采用流式读取以降低内存峰值。

### 视频

- 讲解视频提取高清幻灯片：两遍扫描换页与稳定状态，同一页逐渐出现的内容只保留印刷内容最完整的最终状态；全部唯一页面按“有效首次出现时间”稳定组合为一份完整的一页一图不可编辑 PPTX。若某页在正式讲解前仅短暂误翻、随后存在明显更长的稳定讲解区间，程序会保留全部时间记录但使用正式区间排序；真正只出现一次的短页不会被删除。后加手写圈画、移动文字水印和鼠标优先用同页真实帧回填，慢速长水印会结合完整运动轨迹与局部背景修补，并可保留无损 PNG。同页稳定候选会先进行保守几何配准，再在平坦区域稳健降噪、在文字和表格边缘选择最清晰的真实帧；已经用于水印或批注修复的区域不会被融合或 AI 重新改写。清晰增强可选自动、无独显兼容、GPU AI 和关闭四档；GPU 档使用 Real-ESRGAN 2 倍增强并逐页记录二检和回退情况。支持自动/自定义课件区域、水印搜索区域、水印文字提示、固定水印区域和讲师区域；广告会移动到页面中部或底部时应选择“全画面”或自定义水印区域。长视频中已接受页面只保留紧凑缩略指纹，避免全分辨率画面随页数长期堆积；PNG 可解码性、PPT 页数/图片结构/页面图片哈希顺序、Word 报告时间线及第二遍解码完整性全部通过后才整体提交，失败或取消不会公开半成品。
- 视频 PPT 快速补修：同时添加一份已提取 PPTX 与对应原视频，点击“打开快速补修”。窗口始终并排显示“原 PPT 页面、对应视频画面、处理结果”三幅画面。选择已有页时会优先读取相邻提取报告并自动定位原视频时间；在左图拖框后只需点击一个主按钮，软件自动校正稳定帧并显示右侧结果，再次点击即确认。手写标注过多时可切换“手动选最佳帧替换本页”，在时间轴逐帧选择文字最完整、手写最少的确切画面，并在中间画面连续拖出多个编号水印框；程序严格采用该帧，不再自动改选，再一次性清理全部框选水印。补插漏页时只需选择插入位置并在时间轴找到画面，水印框选为可选。确认所需页面后点击“完成并立即生成新 PPT”，无需保存方案、返回主界面或再次点击开始。输出始终另存新 PPT；原文件不覆盖，未框选区域逐像素复检，自动缺页检测与乱序修复仍保留在常规提取流程中。
- 图片序列或 PDF 页面生成高清 MP4。
- MP4、MKV、MOV 转码，保留自动/H.264/流复制等稳定路径。
- H.264 视频压缩。
- 精准重编码裁剪，避免快速流复制导致的起止时间偏差。
- 提取第一条音轨为无损 WAV。

视频默认使用兼容性优先的自动 H.264 编码路径。字幕、附件、数据流、额外视频流和额外音轨不会自动保留。

幻灯片提取模块使用本机 OpenCV/NumPy 时序分析，不把视频上传到云端，也不依赖 OCR 重输公式。移动遮挡只有在同一页其他时间出现过真实底图时才能精确恢复；永久固定水印、讲师始终遮挡的正文、或页面首次出现时就已有且从未擦除的手写，没有真实像素可回溯，只能保守修补并在报告中标为低可信。请仅处理本人或已获授权的视频。

图片生成视频时，标准画面与淡入淡出中间帧使用无损 PNG，不再用 JPEG 反复压缩；图片预处理会自动并行，并始终按原始选择顺序写入视频。

## 已移出产品界面的功能

以下入口不是简单“置灰”，而是已经从公开任务目录移除，避免对结果质量做过度承诺：

- PDF 表格转 Excel、PDF 转语义 HTML。
- PDF OCR、证书数字签名、坐标式手写签名/批注/表单填写。
- Word 转 Markdown/HTML/EPUB、修订清理、邮件合并、排版级空白页删除。
- Excel 公式转数值、删除空白行列、合并/拆分单元格、工作表综合管理、数据透视表。
- PPT 动画视频、母版重建、PPT 转长图。
- HEIC、RAW、SVG、AI 去背景。
- GIF/ICO 输出、WebM、H.265、AV1、VP9 和手动硬件编码器选择。

## 精度边界

- PDF 是固定版式，Word 是流式版式，任意复杂文件仍无法同时保证像素级原样与完全自然的连续编辑；因此 PDF 转 Word 默认采用版式优先混合，在同一页面中让可靠正文可编辑，并将公式、图表和复杂表格局部高清保留。页面元素严重重叠、文字顺序无法确认或字体无法可靠替代时，仍可能整页高清兜底。
- IEEE/TeX 双栏论文可恢复绝大多数正文与词间空格，但公式、矢量图表和复杂表格通常以局部图像保留，其内部内容不可单独编辑；要求整篇像素级一致时应选择整篇高清原样模式，要求所有内容都可编辑时则应选择全文可编辑并人工复核公式、字体和分页。
- WPS 对中文办公文档通常很实用，但复杂字体、SmartArt、宏、图表和分页仍可能与原应用有差异。
- PDF 无损优化不会降低图片分辨率，因此体积缩减通常有限。
- 图片和视频的目标体积、最高画质和处理速度不能同时保证。
- 所有结果默认另存，不覆盖原文件；同名输出会生成新文件名。

## 构建 Windows 程序

```powershell
.\prepare_portable_dependencies.ps1
.\build.ps1
```

若系统禁止直接运行 PowerShell 脚本，可使用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\prepare_portable_dependencies.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

依赖准备脚本只会获取或接收 FFmpeg 与 Poppler x64 发行包，并校验已固定下载项的 SHA256。WPS、Microsoft Office 与 LibreOffice 均不会被下载或打包。也可通过脚本参数传入已下载的 FFmpeg/Poppler 路径，便于离线构建。

构建结果位于 `dist\LayoutLoom\LayoutLoom.exe`。这是 one-folder 版本，发布时需要复制整个 `dist\LayoutLoom` 文件夹；不得只发送单独的 EXE。构建结束会检查 73 项目录、拖放/Tk 运行时、多进程、Poppler 与 FFmpeg/ffprobe；Office 引擎属于用户本机可选依赖，不作为打包自检的强制条件。

## 生成开源发布包

```powershell
.\release.ps1
```

发布脚本会重新构建并在 `release` 目录生成：

- `LayoutLoom-Windows-x64-Portable-<版本>.zip`：Windows 10/11 x64 便携版，包含 Python 运行时和可再分发引擎。
- `LayoutLoom-Source-<版本>.zip`：同版本完整页织工坊源码、测试和构建脚本，不包含体积巨大的第三方二进制副本。
- `SHA256SUMS.txt`：两个压缩包的 SHA256 校验值。

发布时必须同时提供便携包、源码包、许可证与校验值。AGPL 义务和源码对应关系见 `SOURCE_CODE.md`；第三方许可证见 `THIRD_PARTY_NOTICES.md` 和便携包内的 `THIRD_PARTY_LICENSES`。当前发布目标为 Windows 10/11 x64；不能承诺所有裁剪版 Windows、旧版系统、损坏文件或特殊 Office 安装都可无差异运行。
